# [赛事/靶场] [Reverse] 题目名

> 难度：⭐⭐ | 考点：`IDA 静态分析` `算法还原`

## 题目信息

- 附件：`crackme`（ELF / PE / APK）

## 解题思路

### 1. 基本信息

```bash
file crackme          # 类型、架构
strings crackme | grep -i flag   # 先看有没有明文提示
```

### 2. 静态分析（IDA）

- 找主逻辑：`main` → 关键比较函数
- 识别算法：常见异或、移位、查表、TEA/AES 变种
- 记下常量与变换顺序（顺序很重要）

### 3. 动态调试（如静态卡住）

- gdb / x64dbg 下断点，观察输入如何被变换
- 注意反调试（ptrace、时间检测），必要时 patch

### 4. 逆向算法

拿到加密函数后用 Python 逆推（异或自逆、置换求逆表、对称密码直接解）。

## 总结

- 逆向核心是**还原算法**，先静态后动态，卡住就动手调试
- 常见套路积累：XOR、Base64 变表、TEA 系列、迷宫、约束求解（z3）
